# Here's a quick guide to get started with Markdown (MD)

MARKDOWN files end with (.md)

# **MARKDOWN**

---
 Markdown is a simple way to format text for reports and documentation. (simplicity, readability, and easy to convert into other formats like HTML or PDF).

#### Markdown Basic Syntax Guide

## 1.Headings

<mark>#</mark> symbol is used to create headings.The number of  <mark>#</mark> determines the heading size.


```
# Heading Level 1
## Heading Level 2
### Heading Level 3
#### Heading Level 4
##### Heading Level 5
###### Heading Level 6
```



 ## 2.Paragraphs

Just writing the text would convert it into paragraph.leave a blank line in between to separate paragraph.

This is the first paragraph. 

This is the second paragraph.

## 3.Text Styling

we can apply bold, italic, or bold and italic text using this syntax.

```
**Bold Text**
*Italic Text*
***Bold and Italic Text***
```
Output:
**Bold Text** ,
*Italic Text* ,
***Bold and Italic Text***

## 4.Highlighting Text
A simple syntax to highlight your text.

`<mark>Highlighted</mark>`

Output:
<mark>Highlighted</mark>

## 5.Super/Subscript

For super and subscript, we can use HTML tags inside Markdown.

```
Superscript: <sup>text</sup>
Subscript: <sub>text</sub>
```

Output:
Superscript: <sup>text</sup>
Subscript: <sub>text</sub>

## 6.Code/Code Blocks

 single backticks (`) for single line comment ,
 multi-line code blocks , use triple backticks (```).

`   Helloworld    `

## 7.Comments

 Comments in programming are used to explain and clarify code, making it easier to understand, maintain, and debug.(they wont be displayed).

 `<!--comment-->`

 ## 8.Links

To create links, use square brackets for the text and parentheses for the URL:

`[MARVEL-UVCE](https://hub.uvcemarvel.in/)`

Output: [MARVEL-UVCE](https://hub.uvcemarvel.in/)

## 9.Lists
 we can use dashes (-), asterisks (*), or plus signs (+) for unordered lists.

```
- marvel
+ marvel
* marvel
 ```
 Output: 
 
- marvel     
+ marvel       
* marvel
 
    
## 10. Tables

 tables with pipes (|) and dashes (-) can be created.

``` 
negating boolean values

|expression|  result  | 
|----------|----------|
| ~true    | false    |
| ~false   | true     |
|          |          |
```
Output:

| Expression  | Result |
|-------------|--------|
|  ~true      | false  |
| ~false      | true   |

## 11.Checklist

 We can create a checklist using dashes and brackets:

 ```
 - [ ] t1
- [x] t2(completed)
- [ ] t3
```
output:

- [    ] t1
- [_/] t2 (completed)
- [ ] t3



## 12.Images/GIF
even we can display images here with  the simple syntax.Images can be hosted online or can be opened from the path specified or just drag and drop them.

`syntax: ![Alt text](URL_or_path_to_image)`
